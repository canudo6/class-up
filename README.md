# ClassUp — Mobile

Esta versão foi adaptada para celulares: menu inferior, cartões responsivos, calendário ajustado e suporte a instalação como PWA quando hospedada em HTTPS.

## Para a feira
A forma mais confiável é colocar estes arquivos em uma hospedagem HTTPS, como GitHub Pages, e abrir o endereço no celular. No navegador, use “Adicionar à tela inicial”/“Instalar app” quando disponível.

Substitua `logo.png` pela sua logo (recomendado: 512x512 px).

Observação: este é um protótipo local. Os dados não são compartilhados entre aparelhos; para isso seria necessário um backend/banco de dados.
